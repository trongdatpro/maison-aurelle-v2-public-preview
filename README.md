# Maison Aurelle V2 — Public Visual Preview

Isolated, lightweight Node.js + LiquidJS preview environment for the Maison Aurelle V2 Shopify Online Store 2.0 theme.

## Verified Endpoints
- **Health Check:** `/health`
- **Homepage:** `/`
- **Product Detail Page (PDP):** `/products/aurelle-fluted-marble-pedestal-table`
- **Collection Page:** `/collections/all`

## Local Execution
```bash
npm install
npm start
```
